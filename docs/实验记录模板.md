## 5. 对比实验（预训练 vs 微调）
| 模型 | mAP50 | mAP50-95 | Precision | Recall | 推理(ms/img) |
|---|---:|---:|---:|---:|---:|
| YOLOv8n（预训练） | 0.00537 | 0.00269 | 0.00961 | 0.1160 | 6.6 |
| YOLOv8s（预训练） | 0.00429 | 0.00225 | 0.00800 | 0.0707 | 8.8 |
| 本课题模型（微调） | 0.922 | 0.560 | 0.941 | 0.859 | 6.4 |

**结论要点**：
- 预训练模型在该数据集上几乎不可用，需通过任务域微调
- 微调后模型在 mAP 与 Recall 上显著提升，且推理速度满足实时性要求

## 8. 关键命令（复制即可）
```

cd /d "G:\桌面\毕业设计\smoking-detection"
```

训练：
```
yolo train model=... data=... epochs=... imgsz=... batch=...
```

