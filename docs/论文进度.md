# 论文/项目进度记录（吸烟行为检测与预警系统）

> 用途：保存当前阶段已完成工作、待办事项与材料清单，便于持续撰写论文与答辩准备。

## 1. 项目概况
- **题目**：基于 YOLOv8 的吸烟行为检测与安全预警系统研究
- **核心功能**：图片/视频/摄像头输入检测 + 稳态触发 + 冷却机制 + 留证截图 + 事件日志（CSV）+ Web 演示界面
- **数据集**：Roboflow `detect smoking behavior v6`（单类 `Smoking`，train 600 / val 173 / test 80）

## 2. 当前代码实现状态（以 `smoking-detection-deploy` 为准）
### 2.1 推理与预警（命令行）
- **脚本**：`scripts/detect.py`
- **策略**：连续帧稳态触发 + 冷却机制
- **留证输出**：
  - 截图：`runs/detect/events/event_*.jpg`
  - 日志：`runs/detect/events/event_log.csv`

### 2.2 Web 演示界面（Streamlit）
- **入口**：`run_app.py`
- **页面**：

  - 视频检测（已支持：触发预警时保存留证截图+写入 `event_log.csv`）
  - 摄像头监控（WebRTC 模式 + OpenCV 兼容模式）

### 2.3 训练/验证/导出脚本
- `scripts/train.py`：训练脚本（参数后续以训练日志/最终实验为准）
