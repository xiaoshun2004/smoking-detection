摘要

本文提出了一种新的目标检测方法 YOLO。以往的目标检测工作通常是将分类器改造后用于检测任务，而本文将目标检测重新表述为一个回归问题，直接回归到空间上分离的边界框以及对应的类别概率。单个神经网络只需对整幅图像进行一次前向计算，便可直接预测边界框和类别概率。由于整个检测流程就是一个单一网络，因此可以围绕检测性能进行端到端优化。

该统一架构具有极高的速度优势。基础版 YOLO 模型可达到 45 帧每秒的实时处理速度；其轻量版本 Fast YOLO 可达到 155 帧每秒，同时其 mAP 仍然是其他实时检测器的两倍。与当时最先进的检测系统相比，YOLO 的定位误差更多，但在背景区域上产生误检的概率更低。最后，YOLO 学到的是一种更具泛化性的目标表示。当从自然图像迁移到艺术图像等其他领域时，YOLO 的表现优于包括 DPM 和 R-CNN 在内的其他检测方法。

1. 引言

人类只需扫视一幅图像，便能立刻知道图中有什么物体、它们位于哪里以及它们之间如何交互。人类视觉系统既快速又准确，因此我们能够几乎不经思考地完成驾驶等复杂任务。若能得到快速且准确的目标检测算法，计算机就有可能在没有专用传感器的条件下进行自动驾驶，也能够帮助辅助设备向用户实时传递场景信息，并推动通用型、具备快速响应能力的机器人系统发展。

当前的检测系统大多是将分类器“改造”为检测器。为了检测某个目标，这些系统往往在测试图像的不同位置和尺度上反复运行分类器。以可变形部件模型为代表的方法采用滑动窗口策略，在整幅图像上按固定间隔不断运行分类器。

较新的方法如 R-CNN，则先利用候选区域生成方法在图像中提出可能的边界框，再对这些候选框逐一分类。分类完成后，还需要借助后处理步骤来修正边界框、删除重复检测结果，并结合场景中的其他物体重新对候选框打分。由于各个组件都要分开训练，这类复杂流水线不仅速度慢，而且难以整体优化。

本文将目标检测重新定义为一个单一的回归问题，即直接从图像像素回归到边界框坐标和类别概率。借助这一系统，我们只需“看一次”图像，就能预测图中有哪些目标以及它们的位置。

YOLO 的设计非常简洁。单个卷积网络可以同时预测多个边界框以及这些边界框对应的类别概率。YOLO 在整幅图像上训练，并直接围绕检测性能进行优化。与传统目标检测方法相比，这种统一模型具有若干显著优势。

首先，YOLO 非常快。由于我们将检测视为回归问题，因此不再需要复杂的处理流水线。在测试阶段，只需将新图像输入神经网络即可得到检测结果。基础版网络在 Titan X GPU 上无需批处理即可达到 45 fps，快速版甚至超过 150 fps。这意味着系统可以在低于 25 毫秒延迟的情况下对视频流进行实时处理。此外，YOLO 的平均精度均值超过了其他实时系统的两倍。

其次，YOLO 在进行预测时能够从全局角度理解整幅图像。与滑动窗口方法或候选区域方法不同，YOLO 在训练和测试时都能够看到整张图像，因此它会隐式编码类别的上下文信息以及外观信息。Fast R-CNN 之所以会把背景区域误当作目标，一个重要原因就是它无法看到更大的上下文范围。相比之下，YOLO 的背景误检数量不到 Fast R-CNN 的一半。

第三，YOLO 学到了具有较强泛化能力的目标表示。当模型在自然图像上训练、在艺术图像上测试时，YOLO 依然明显优于 DPM 和 R-CNN 等先进方法。正因为其泛化性更强，YOLO 在面对新领域或异常输入时不容易失效。

当然，YOLO 在精度方面仍落后于当时最先进的检测系统。尽管它能快速识别图像中的目标，但在某些情况下，尤其是面对小目标时，其精确定位能力仍然不足。论文后续实验对这些权衡关系进行了进一步分析。

2. 统一检测框架

本文将目标检测中的多个独立组件统一为一个单一神经网络。该网络利用整幅图像的特征来预测每一个边界框，同时还能在同一张图像上、跨所有类别同时预测所有边界框。这意味着网络能够从整幅图像和全部目标的整体层面进行推理。YOLO 的设计使得模型既能实现端到端训练，又能保持实时速度，同时还能维持较高的平均精度。

系统首先将输入图像划分为一个 S x S 的网格。如果某个目标的中心点落入某个网格单元中，那么该网格单元就负责检测该目标。

每个网格单元预测 B 个边界框以及这些边界框的置信度分数。置信度既反映模型对该框是否包含目标的确信程度，也反映模型对该预测框与真实框重合程度的判断。可以将其理解为 Pr(Object) 与预测框和真实框之间 IOU 的乘积。若该网格单元中不存在目标，则对应的置信度应为 0；若存在目标，则置信度应尽量接近预测框与真实框之间的交并比。

每个边界框包含 5 个预测量：x、y、w、h 以及 confidence。其中 x 和 y 表示目标中心相对于当前网格单元边界的位置；w 和 h 表示相对于整幅图像的宽度和高度；confidence 表示预测框与任一真实框之间的 IOU。

每个网格单元还会预测 C 个条件类别概率，即 Pr(Class i | Object)。这些概率的前提是该网格单元中存在目标。无论该网格单元预测多少个边界框，类别概率只预测一组。

在测试阶段，将条件类别概率与边界框的置信度相乘，就可以得到每个边界框对应的类别特定置信度分数。这些分数既表示该框中出现某类别的概率，也体现该预测框与真实目标的匹配程度。论文在 PASCAL VOC 数据集上评估时设定 S = 7、B = 2。由于 VOC 有 20 个类别，因此 C = 20，最终输出张量为 7 x 7 x 30。

2.1 网络设计

作者将该模型实现为一个卷积神经网络，并在 PASCAL VOC 检测数据集上进行评估。网络前部的卷积层负责从图像中提取特征，后部的全连接层用于预测最终的类别概率和边界框坐标。

网络结构借鉴了 GoogLeNet 图像分类模型。整个网络包含 24 个卷积层和 2 个全连接层。与 GoogLeNet 使用 inception 模块不同，YOLO 采用的是 1 x 1 的降维卷积层与 3 x 3 卷积层交替组合的方式。作者先在 ImageNet 分类任务上以 224 x 224 的分辨率对卷积层进行预训练，然后在检测任务中将输入分辨率提升到更高水平。

论文还提出了一个速度更快的版本 Fast YOLO，用于进一步探索高速目标检测的性能边界。Fast YOLO 仅使用 9 个卷积层，而不是 24 个，并且每层卷积所用的滤波器数量也更少。除了网络规模不同之外，YOLO 与 Fast YOLO 的训练和测试设置保持一致。

该网络最终输出一个 7 x 7 x 30 的预测张量。

2.2 训练过程

作者首先在 ImageNet 1000 类分类竞赛数据集上对卷积层进行预训练。预训练时使用前 20 个卷积层，随后接一个平均池化层和一个全连接层。该分类网络训练约一周后，在 ImageNet 2012 验证集上取得了 88% 的 single-crop top-5 准确率。所有训练与推理工作都在 Darknet 框架上完成。

完成预训练后，作者将模型转换为检测模型。参考已有研究，他们在网络后部增加了 4 个卷积层和 2 个随机初始化的全连接层。由于检测任务更依赖细粒度视觉信息，网络输入分辨率也从 224 x 224 提升到了 448 x 448。

网络最后一层同时预测类别概率和边界框坐标。边界框的宽度和高度都用图像宽高进行归一化，因此其取值落在 0 到 1 之间；x 和 y 则被建模为相对于某个网格单元位置的偏移量，因此同样被限制在 0 到 1 之间。最后一层采用线性激活函数，其余各层使用 leaky ReLU 激活函数。

模型使用平方和误差作为优化目标。这个目标函数较易优化，但与“最大化平均精度”这一最终目标并不完全一致。它会将定位误差与分类误差同等对待，这未必是最佳选择。另外，在每张图像中，大量网格单元其实并不包含任何目标，这会把这些网格单元的置信度分数强烈压向 0，从而掩盖真正含有目标的网格单元所产生的梯度，导致训练不稳定，甚至在早期发散。

为了解决这一问题，作者增大了边界框坐标预测的损失权重，同时减小了不含目标的边界框置信度损失权重。论文引入了两个超参数：lambda_coord 和 lambda_noobj，并设置 lambda_coord = 5、lambda_noobj = 0.5。

平方和误差还会对大框和小框的误差一视同仁，但在实际中，大框上的微小偏差通常影响较小，而小框上的同样偏差会更严重。为缓解这一问题，模型并不是直接预测宽高，而是预测宽高的平方根。

在训练阶段，每个目标只希望由一个边界框预测器负责。具体做法是：在同一网格单元中，选择当前预测结果与真实框 IOU 最高的那个预测器作为“责任预测器”。这种机制会带来预测器之间的专业化分工，使得不同预测器更擅长于不同尺度、长宽比或类别的目标，从而提高整体召回率。

损失函数只在网格单元中存在目标时惩罚分类误差；同时，也只有在某个预测器被指定为该真实框的责任预测器时，才惩罚该预测器的边界框坐标误差。

网络在 PASCAL VOC 2007 与 2012 的训练集和验证集上共训练约 135 个 epoch。在 2012 测试时，还将 VOC 2007 的测试集加入训练。整个训练过程中，batch size 为 64，动量为 0.9，权重衰减为 0.0005。

学习率采用分阶段策略。训练初期先将学习率从 10^-3 缓慢提升到 10^-2；随后以 10^-2 训练 75 个 epoch，再以 10^-3 训练 30 个 epoch，最后以 10^-4 训练 30 个 epoch。为了避免过拟合，作者使用了 dropout 和大量数据增强。第一个全连接层之后使用丢弃率为 0.5 的 dropout 层，以降低层间协同适应；数据增强则包括最多 20% 范围的随机缩放和平移，以及在 HSV 空间中对曝光和饱和度的随机调整。

2.3 推理过程

与训练阶段类似，对测试图像进行检测也只需要一次网络前向计算。在 PASCAL VOC 上，网络每张图像预测 98 个边界框及对应的类别概率。由于 YOLO 只需一次网络计算，不像基于分类器的方法那样需要多阶段处理，因此在测试阶段速度极快。

网格化设计天然保证了边界框预测的空间多样性。通常情况下，目标所属的网格单元是比较明确的，因此网络往往只会为每个目标预测一个边界框。但对于一些大目标，或者位于多个网格边界附近的目标，多个网格单元都可能给出较好的定位结果。此时可以使用非极大值抑制来去除重复检测。虽然它不像在 R-CNN 或 DPM 中那样关键，但仍能带来 2% 到 3% 的 mAP 提升。

2.4 YOLO 的局限性

YOLO 对边界框预测施加了较强的空间约束，因为每个网格单元只能预测两个边界框，并且只能对应一个类别。这会限制模型对彼此相邻目标的表达能力，因此对于成群出现的小目标，例如一群鸟，模型往往表现较差。

由于模型是从数据中直接学习如何预测边界框的，因此当目标具有新的、异常的长宽比或结构布局时，其泛化能力也会受到影响。此外，网络在从输入图像逐步下采样的过程中，预测边界框所使用的特征相对较粗，这也会影响定位精度。

最后，尽管训练所用损失函数是在近似检测性能，但它对小框和大框中的误差处理方式相似。然而在实际中，大框上的小误差通常影响有限，而在小框上却可能显著降低 IOU。YOLO 最主要的误差来源就是定位不准确。

3. 与其他检测系统的比较

目标检测是计算机视觉中的核心问题。典型的检测流程通常先从输入图像中提取一组鲁棒特征，然后再通过分类器或定位器在特征空间中识别目标。这些分类器或定位器可能在整幅图像上以滑动窗口方式运行，也可能只在部分候选区域上运行。论文将 YOLO 与多个代表性检测框架进行了对比，并分析了它们之间的主要异同。

可变形部件模型采用滑动窗口方式进行目标检测。DPM 使用分离式流水线来提取静态特征、对区域进行分类、为高分区域预测边界框等。YOLO 则用一个卷积神经网络取代了这些分散的环节。该网络能够同时完成特征提取、边界框预测、非极大值抑制以及上下文推理。它不再依赖静态特征，而是直接在检测任务中联合学习并优化特征。因此，这种统一结构比 DPM 更快，也更准确。

R-CNN 及其变体使用候选区域而不是滑动窗口来寻找图像中的目标。Selective Search 先生成候选框，卷积网络提取特征，SVM 进行打分，线性模型修正边界框，最后再通过非极大值抑制去除重复结果。这个流水线中的每个阶段都需要分别精细调参，因此整体系统速度很慢。

YOLO 与 R-CNN 有一定相似之处，例如都要对候选位置进行评分，但 YOLO 的候选框是由网格单元直接生成的，并且附带空间约束，这有助于减少同一目标的重复检测。YOLO 每张图像只提出 98 个边界框，而 Selective Search 大约会产生 2000 个候选框。更重要的是，YOLO 将这些原本分离的组件统一进一个联合优化模型之中。

Fast R-CNN 与 Faster R-CNN 通过共享计算和利用神经网络生成候选区域，改进了 R-CNN 框架。尽管它们相较原始 R-CNN 在速度和精度上都有提升，但仍未真正达到实时性能。同时，也有许多工作尝试通过加速 HOG 计算、使用级联结构以及 GPU 并行来提高 DPM 的速度，但真正达到实时水平的仍然有限。

YOLO 并不是去优化一个庞大检测流水线中的某个局部，而是从根本上抛弃了这条流水线，因此它在设计上天然具备高速优势。与只针对单一类别（例如人脸或行人）进行高度优化的专用检测器不同，YOLO 是一个通用型检测器，能够同时学习多个类别的检测任务。

论文还将 YOLO 与 Deep MultiBox 和 OverFeat 进行了比较。尽管这些方法同样使用卷积网络来预测目标位置，但它们本质上仍是更大检测流程中的一个环节，而 YOLO 则是一个完整的检测系统。作者还指出，YOLO 的设计与其此前关于 MultiGrasp 的工作存在一定联系，但目标检测要困难得多，因为它必须同时预测多个目标的类别、位置与尺寸。

4. 实验

论文首先在 PASCAL VOC 2007 上将 YOLO 与其他实时检测系统进行了比较。为了分析 YOLO 与 R-CNN 系列之间的差异，作者进一步研究了 YOLO 与 Fast R-CNN 在 VOC 2007 上的错误类型分布。在此基础上，他们证明可以利用 YOLO 对 Fast R-CNN 的检测结果重新打分，从而减少背景误检并显著提升性能。论文还给出了 VOC 2012 上的实验结果，并将 mAP 与当时最先进的方法进行了比较。最后，作者在两个艺术图像数据集上验证了 YOLO 的跨领域泛化能力。

4.1 与其他实时系统的比较

根据论文给出的结果，Fast YOLO 是当时 PASCAL 数据集上速度最快的目标检测器。它在达到 52.7% mAP 的同时，精度仍是此前实时检测方法的两倍以上。标准版 YOLO 则在保持实时性能的同时，将 mAP 提升到了 63.4%。

作者还使用 VGG-16 训练了一个更高精度版本的 YOLO，但这一版本速度明显更慢，因此后续分析主要围绕更快的模型展开。

Fastest DPM 在几乎不损失 mAP 的情况下提升了 DPM 速度，但仍距离真正实时差一倍左右。R-CNN minus R 的速度比原始 R-CNN 更快，但由于缺少高质量候选区域，其精度受到明显影响。Fast R-CNN 提升了分类阶段效率，但仍依赖 Selective Search，而后者生成候选框大约需要每张图像 2 秒，因此仍远达不到实时。

Faster R-CNN 用神经网络替代 Selective Search 来生成候选框。论文中的测试结果显示，其精度最高的模型约为 7 fps，而较小、精度较低的版本约为 18 fps。VGG-16 版本 Faster R-CNN 的 mAP 高出 YOLO 约 10 个点，但速度也慢了大约 6 倍；Zeiler-Fergus 版本与 YOLO 的速度差距较小，但精度也更低。

4.2 VOC 2007 误差分析

为了更深入地比较 YOLO 与先进检测器之间的差异，论文对 VOC 2007 上的检测结果进行了细粒度误差分析。作者将 YOLO 与 Fast R-CNN 进行比较，因为后者是 PASCAL 上性能最强的检测器之一，并且公开了检测结果。

论文将每个高置信度预测划分为不同错误类型，例如正确检测、定位错误、相似类别混淆、其他类别混淆以及背景误检等。分析结果表明，YOLO 的主要问题在于定位不够准确。定位误差在 YOLO 的全部错误中占比最高，甚至超过其他各类错误之和。

相比之下，Fast R-CNN 的背景误检更多。论文指出，Fast R-CNN 顶层检测结果中有 13.6% 实际上并不包含任何目标。也就是说，Fast R-CNN 产生背景误检的概率几乎是 YOLO 的 3 倍。

4.3 结合 Fast R-CNN 与 YOLO

由于 YOLO 在背景误检方面明显少于 Fast R-CNN，作者尝试利用 YOLO 来剔除 Fast R-CNN 的背景误检，从而获得性能提升。具体来说，对于 R-CNN 预测出的每一个边界框，都去检查 YOLO 是否也预测了相似的边界框；若存在，则根据 YOLO 给出的概率以及两个框之间的重叠程度来提高该检测结果的得分。

实验表明，组合后的系统使 mAP 提升了 3.2%，达到 75.0%。作者还尝试将最佳 Fast R-CNN 模型与若干其他 Fast R-CNN 变体进行集成，但这些组合仅带来了 0.3% 到 0.6% 的小幅提升。这说明 YOLO 带来的收益并不只是一般意义上的模型集成效果，而是因为 YOLO 的错误类型与 Fast R-CNN 不同，特别擅长抑制背景假阳性。

当然，这种组合系统并不会继承 YOLO 的速度优势，因为两个模型仍需分别运行后再进行结果融合。不过，由于 YOLO 本身速度很快，相比 Fast R-CNN 并不会额外增加太大的计算负担。

4.4 VOC 2012 结果

在 VOC 2012 测试集上，YOLO 取得了 57.9% 的 mAP。这个结果虽然低于当时最先进的方法，但与使用 VGG-16 的原始 R-CNN 相对接近。系统在小目标上的表现不如竞争方法，例如在 bottle、sheep 和 tv-monitor 等类别上，YOLO 比 R-CNN 或 Feature Edit 低 8 到 10 个百分点；但在 cat、train 等类别上，YOLO 又取得了更高的性能。

论文中的 Fast R-CNN + YOLO 组合模型在公开排行榜上属于表现最强的一批检测方法之一。与单独使用 Fast R-CNN 相比，加入 YOLO 后的组合方案额外提升了 2.3%，使其在排行榜上上升了 5 个名次。

4.5 泛化能力：艺术图像中的行人检测

学术界常用的目标检测数据集，通常默认训练集和测试集服从相同的数据分布。但在真实应用中，测试数据往往与训练数据存在明显差异。为了验证模型面对分布偏移时的鲁棒性，论文在 Picasso Dataset 和 People-Art Dataset 上比较了 YOLO 与其他检测系统，这两个数据集都用于测试艺术图像中的行人检测能力。

R-CNN 在 VOC 2007 上具有较高 AP，但应用到艺术图像后性能下降明显。这是因为 Selective Search 是针对自然图像调优的，而 R-CNN 的分类阶段只能看到较小的局部区域，因此对候选框质量依赖很强。

DPM 在艺术图像上的 AP 保持得更稳定。已有研究认为，这是因为 DPM 对目标的形状和空间布局有较强建模能力。不过，DPM 在原始基准上的初始 AP 本身就较低。

YOLO 在 VOC 2007 上表现良好，而且迁移到艺术图像后，其 AP 下降程度小于其他方法。与 DPM 类似，YOLO 不仅建模目标的尺寸和形状，还能学习目标之间的关系以及目标通常出现的位置。虽然艺术图像和自然图像在像素层面差异很大，但在目标尺寸和形状层面仍具有相似性，因此 YOLO 依然能够预测出较好的边界框和检测结果。

5. 真实场景下的实时检测

YOLO 是一种兼具速度和精度的目标检测器，因此非常适合实际计算机视觉应用。作者将 YOLO 连接到摄像头上，并验证系统在考虑图像采集和结果显示开销的情况下，依然能够保持实时性能。

得到的系统具有较强的交互性和直观性。虽然 YOLO 本质上仍是逐帧处理图像，但当它接入摄像头后，整体表现类似于一个跟踪系统，可以随着目标在场景中的移动和外观变化持续进行检测。

6. 结论

本文提出了 YOLO，这是一种统一的目标检测模型。该模型结构简单，能够直接在整幅图像上训练。与基于分类器的检测方法不同，YOLO 所使用的损失函数直接对应检测性能，而且整个模型是联合训练的。

Fast YOLO 在论文发表时被认为是文献中速度最快的通用目标检测器，而标准 YOLO 则推动了实时目标检测的性能发展。与此同时，YOLO 在新领域上的泛化能力也较强，因此特别适合需要快速且鲁棒检测能力的实际应用场景。
